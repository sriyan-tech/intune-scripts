# Intune Scripts

This repository contains PowerShell scripts used for automating Microsoft Intune device management tasks.

## Scripts Included
- Get-IntuneDevices.ps1 — Retrieves all Intune-managed devices using Microsoft Graph API.

## Purpose
These scripts are used for learning, testing, and automating:
- Device compliance reporting
- Device inventory retrieval
- Microsoft Graph API operations
- Intune administration tasks
